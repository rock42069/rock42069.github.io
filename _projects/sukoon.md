An open-source, multi-agent mental health support system built with **People + AI, EkStep Foundation** (Jul 2024 – Dec 2024).

## Highlights

- Developed a **multi-agent system using LangGraph** with GPT-4/Claude and clinically-aligned agents for safe, empathetic conversations.
- Deployed the platform on **WhatsApp** and **Streamlit** with a Python backend.
- Conducted large-scale testing with **581 users**, achieving a **34% increase in daily engagement**.
- Co-authored the accompanying open-source paper; coordinated **600+ participants, 50+ health workers, and 10+ NGOs** for the pilot at IIT Kanpur.
