A team recommendation system built for the Dream11 problem statement at **Inter IIT Tech Meet 13.0** (Dec 2024).

## Highlights

- Built an ML pipeline combining **neural networks and boosting** to optimize playing-XI selection.
- Engineered **100+ contextual features**, using **RFE + SHAP** for feature selection and interpretability.
- Developed a modular backend with a **React UI** enabling drag-and-drop team customization and real-time analytics.
- Deployed an **LLM assistant** offering multilingual insights and strategic recommendations.
